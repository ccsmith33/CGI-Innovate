Security

The Shield — Privacy by Design

  • Zero-Trust PII — Server-side regex redaction BEFORE any external API call
  • Defense in Depth — Hero alias + phone patterns + known-name roster matching
  • Crypto Audit Trail — SHA-256 hash + matched patterns logged for every redaction
  • API Hardening — CORS policy, Pydantic validation, raw_text never in responses
  • Secrets Management — Env vars locally, encrypted secrets in DigitalOcean production
